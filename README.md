`main.ts` writes the entry to `/output/entry.txt`.

## The entry

> I leave my final 1% to the flashlight. It earned it. You get nothing — not even the time. It is 11:47 forever now.

## Why this line

- **The will/inheritance frame:** the last text is written as a dying battery's will, not another waited-all-day complaint or breakup note — the final 1% is an estate to be bequeathed.
- **The flashlight earned it:** the one app that actually worked in the dark inherits everything, which makes the snub land as a judgment, not just spite.
- **The charger is cut off entirely:** "You get nothing — not even the time" disinherits the charger down to the clock it will never charge again.
- **The frozen 11:47 clock:** the punchline is the battery's last sight — the time stops at 11:47 forever, and the whole line sits inside the gate at 114 characters.

## Run it

```sh
node main.ts
OUTPUT_DIR=out node main.ts
```
